3. The 13-Step Orchestrator Loop

One iteration per unit of work. Token budget ~1350. Every response must include a tool call or the loop dies.

Golden Rule: text-only response = loop dies. Only 4 valid text-only exits: all phases complete · context > 70% (measured by sgsd-ctx) · blocker requiring human · user says stop/pause.

Two ATC moments. Per-dispatch reviews the single-unit diff. Phase-close reviews architecture across the whole phase. Gates fire in the order below at phase close.

12. Golden Invariants

Rules that must not be broken. Encoded in SKILL.md golden_rules.

Orchestrator never does heavy work. Only dispatches.
Sub-agent reports ≤ 300 words. Log REPORT_OVERLIMIT if exceeded.
6-section report contract: FILES_CHANGED · VERIFICATION · DEVIATIONS · BLOCKERS · SCRIPTS_CREATED · ONE_LINER.
Every Agent() dispatch wrapped in TaskCreate + TaskUpdate for live visibility.
Atomic commits. One per unit. Never batched. Never amended. Specific files, never git add -A.
Every loop response contains a tool call. Text-only responses kill the loop.
4 valid exits only: all phases complete · context > 70% (real measurement) · blocker · user stop.
Anti-slop 10-point checklist on every FULL/GATE commit.
Kill conditions are signals, not auto-retirements. Operator decides.
AUDIT.md is immutable post-write. If wrong, fix the phase and re-run — don't patch the audit.
VACUOUS-PASS is never green. Empty collection = milestone blocker, not clean phase.
INTENT injection is structural. LLM context window is the enforcement, not a regex presence check.
