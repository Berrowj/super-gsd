Q4 · PROTOCOL
AGP conformance or SGSD idiom?
4b (borrow vocab)

7. Triple Hallucination Gate — Three Independent Safeguards

Each gate was proposed by a different board member in Round 2 and survived critique from the others. Each targets a distinct failure mode. Stacked together, cost is 1 extra Haiku call + 1 human rating per milestone close. Stacking was the CEO synthesis.

Architect · Gate 1
Typed Hypothesis Tier
type=trajectory-hypothesis
All distilled output writes to trajectory-hypothesis/, never trajectory-lesson/, until v1.3 cross-milestone confirmation. Classifier read-path is firewall-blocked from the hypothesis tier.
Targets: premature surfacing of uncalibrated patterns into dispatch decisions.
Moonshot · Gate 2
Two-Phase Citation Gate
second Haiku pass · sgsd-distill-milestone.sh
Each candidate pattern must cite ≥2 distinct phase references (commit SHA or plan ID). Singletons route to candidate/ subdirectory. Cost: ~400 tokens per run (one extra Haiku call).
Targets: single-phase coincidences hallucinated as cross-cutting patterns.
Contrarian · Gate 3
Novelty-Rating Kill Switch
metrics/distillation-novelty.jsonl · v1.2 close
Operator rates every surviving hypothesis on a 3-point novelty scale before commit. Median < 2/3 across hypotheses at v1.2 close = delete sgsd-distill-milestone.sh. No iteration, no face-saving — real kill.
Targets: the mechanism itself. If distillation produces nothing a human reader wouldn't already know, the script is negative value.
Why three and not one: each gate addresses a different failure mode. Gate 1 protects downstream dispatch from bad surfacing. Gate 2 protects hypothesis quality from single-phase coincidences. Gate 3 protects the mechanism itself from producing obvious-lessons-dressed-as-insights. Removing any one leaves a live failure path.

10. Explicitly Deferred

What we are NOT building — and the concrete trigger that would re-open the decision. Every item logged so this remains evidence-gated rather than forgotten.

Prompts as typed resources. DLB-03's structural-injection principle keeps prompt content in the context window, not a registry. Splitting prompts out of SKILL.md would fight DLB-03. Re-open if: prompt-template drift across SKILL.md files causes measurable dispatch divergence.
Environments as typed resources. No v1.2 consumer. Working directory, .mcp.json, permissions, running processes — not currently failure modes. Re-open if: MCP state drift or permission drift causes a measurable dispatch failure.
Auto-commit SEPL (Q2 options b/c). Violates "operator decides kill conditions" invariant. Operator queue must prove overwhelmed first. Re-open if: operator-gated queue proves bottlenecked across 2+ milestones.
Full AGP spec conformance (Q4 option a). Autogenesis is 3 days old. Spec may churn. Vocabulary borrowed, schema not. Re-open if: Autogenesis stabilises (6+ months post-pub, no breaking revisions) AND a real interop case emerges.
Typed rollback primitive. Pragmatist R2 verdict: git revert covers 95% of SGSD rollback cases. "Typed rollback" is marketing. Re-open if: someone names a concrete failure git revert cannot handle.
Classifier consult of trajectory-lessons (Wave D). Evidence-gated by DLB-02 and this DLB: ≥2 milestones of trajectory data + cross-milestone recurrence before read-path wires. Re-open at: v1.3 milestone close IF trajectory-hypothesis promotion produces any classifier-readable lessons.

12. DLB Lineage — Same Principle, Four Vocabularies

The pattern across DLB-01→04: the board keeps converging on the same architectural principle — structure over ceremony, evidence before machinery, kill conditions that actually kill — under different vocabularies. DLB-04 borrows AGP terminology because it's useful shorthand for principles the project already held.

DLB-01 · 2026-04-19
Memory Topology
Filesystem over MCP. Structure over infrastructure. 40-file tripwire for BM25.
DLB-02 · 2026-04-19
MUDA Learning Loop
Write-path first. No seed library. Evidence before machinery. Kill if no recurrence in 2 milestones.
DLB-03 · 2026-04-19
Intent Continuity
Structural injection, not presence checks. Context window enforces, not regex. Content-quality kill.
DLB-04 · 2026-04-19
Self-Evolving Resource Substrate
Manifest only with named consumer. Trajectory-hypothesis not lesson. Triple hallucination gate. Operator-gated SEPL.
Cross-DLB coherence check: DLB-04 is consistent with all three predecessors. DLB-01 (git-native, no external infra) ✓ — local filesystem + git only. DLB-02 (operator-gated, evidence-first, real kills) ✓ — all three new components carry kill conditions, none auto-commit. DLB-03 (structural over theatrical) ✓ — hypothesis/lesson tier separation is structural, classifier firewall is mechanical not regex.
