What counts as improvement

The win is not just fewer tokens. The real win is that context now has shape: phase capsules, legal context keys, packet manifests, route decisions, source hashes, admission checks, and cache projections.

Before v1.9After v1.9
Long orchestration turns carried broad project history.Context packets carry the current phase, relevant links, and signed evidence.
Agents repeatedly rediscovered prior phase facts.Phase capsules and indexes provide compact handover facts.
Research could scan internal files without clear admission.VTP and research routes are gated by question type and source class.
Redis was an idea for memory.Redis is explicitly projection-only with SQLite/files as canonical truth.

How to read the numbers without fooling ourselves

1. Context traffic is not the same as bill

These totals include cache-read tokens. They show how much context SGSD moved through the model, not a direct invoice line.

2. Older rows have attribution drift

v1.9 fixed attribution. Some old phase labels are noisy, so period totals use milestone stamps while phase bars use known v1.9 phases.

3. After-v1.9 is early but meaningful

v2.0-v2.1 telemetry is lighter and cleaner, but it should keep being watched as more runs accumulate.
