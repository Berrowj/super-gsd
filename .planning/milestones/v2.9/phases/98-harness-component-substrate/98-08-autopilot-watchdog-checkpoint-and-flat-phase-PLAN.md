# 98-08 Autopilot Watchdog Checkpoint And Flat Phase Plan

## Goal

Fix the autopilot watchdog so it cannot overwrite operator/orchestrator checkpoints and so flat `.planning/phases/` artifacts count as durable progress.

## Scope

1. Add regression coverage to `super-gsd/tools/autopilot-watchdog/check.cjs` self-test for:
   - `--checkpoint` preserving an existing checkpoint not generated by the watchdog.
   - watchdog-authored checkpoints remaining overwriteable.
   - active phase lookup finding `.planning/phases/{phase}-...` as well as milestone-scoped phase folders.
2. Patch `writeOutputs()` so `.planning/AUTOPILOT-RECOVERY.md` remains watchdog-owned and overwriteable, while `.planning/ORCHESTRATOR-CHECKPOINT.md` is only written when absent or already generated by the same watchdog version.
3. Patch active phase discovery to check both milestone-scoped and flat phase layouts.
4. Propose, but do not apply, the `.planning/STATE.md` stale duplicate-key cleanup.

## Non-Goals

- Do not mutate `.planning/STATE.md` in this change.
- Do not alter stall thresholds, recovery markdown content, or stall-log dedupe semantics.
- Do not touch unrelated runtime metrics or cockpit state files.

## Verification

- `node super-gsd/tools/autopilot-watchdog/check.cjs --project-dir . --json`.
