## Warnings

- **W-1 (anti-slop #9): JSONL type safety on tag flags.** `--phase` is
  interpolated bare (L205: `phase_field="$PHASE_TAG"`) expecting a number.
  If a caller passes `--phase abc`, the emitted row is `"phase":abc` —
  invalid JSON, will break jq/log-parsers downstream. Fix: either
  validate numeric at parse time or quote it (treat phase as string).
  Plan says `--phase N` but no runtime enforcement.
- **W-2 (plan deviation): `unset OPENAI_API_KEY` is not performed.** Plan
  T1.1 and Scope line 20 say "then `unset OPENAI_API_KEY` defensively".
  Script header (L10-13) argues against that — refuse-to-run only, no
  silent-unset. This is the correct behavior, but the plan text was not
  updated to match. The deviation is captured in code comments, not in
  the plan. Recommend amending plan 14-01 to match, OR updating the
  script to match the plan. A3 is literally satisfied (refuse-to-run +
  exit 4); this is a documentation drift, not a behavioral bug.

## Info

- **I-1: Dead awk stderr marker.** L254 writes `CONTRACT_VIOLATION` to
  awk's `/dev/stderr`, but the wrapper checks `awk_rc != 0 || -z parsed`
  (L266) and never reads the marker. Cosmetic; remove the print or wire
  it into the error message.
- **I-2: `RESOLVED_CMD` duplication.** L144 builds the display string;
  L167 re-types the invocation. Single source of truth would eliminate
  drift risk (e.g., someone adds `--foo` to the real call and forgets
  the display).
- **I-3: Config lookup uses `$ROOT`, not `$PROJECT`.** L115 reads
  `$ROOT/.planning/config.json` even when `--project` points elsewhere.
  Edge case: caller passes `--project /other/repo` but config comes
  from cwd's repo. Plan doesn't specify; document or switch to
  `$PROJECT/.planning/config.json`.

## Recommended Fixes (non-blocking)

1. (W-1) Add numeric validation for `--phase` or quote it as string in JSONL.
2. (W-2) Amend plan 14-01 Scope + T1.1 to reflect refuse-to-run-only
   behavior (strike "defensively unsets it either way").
3. (I-1) Delete L253-254 awk stderr print (dead signal).
4. (I-2) Use `$RESOLVED_CMD` (or a function) for both display and real invocation.
5. (I-3) Clarify config-lookup scope in README.

All fixes can be bundled into a follow-up commit on plan 14-01 or rolled
into 14-02. None block the 14-01 ship.
