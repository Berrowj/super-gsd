# Plan 07-02: Validate Transition Skill and Create VERIFICATION.md

## Objective
Verify `/gsd-transition` skill references correct file paths, handles missing `.gsd/` gracefully, and produces a valid TRANSITION-REPORT.md. Create Phase 7 VERIFICATION.md attesting all 5 requirements are met.

## Tasks

### Task 1: File Path Audit for gsd-transition
type: auto

Audit `super-gsd/skills/gsd-transition/SKILL.md` for:
1. All path references — verify they match actual `.gsd/` structure from GSD 2.0 (Pi harness)
2. ByteRover curate commands — verify domain paths match actual `.brv/context-tree/` subdirectories created by `install.sh` (patterns, anti-patterns, expertise, decisions, error-rules, scripts, domain)
3. Step 6 TRANSITION-REPORT.md template — verify all placeholders have corresponding logic in earlier steps
4. The `$ARGUMENTS` path defaulting to `./.gsd/` — verify this is documented clearly

Done when: all path references verified or corrected.

### Task 2: Missing .gsd/ Graceful Failure
type: auto

Check that SKILL.md Step 1 uses existence checks before reading files. Verify:
- `ls "$GSD_DIR/STATE.md" ... 2>/dev/null` pattern exists (suppresses errors)
- Step reports what was FOUND (not what's missing as an error)
- If no .gsd/ found at all, the skill can report "No GSD 2.0 artifacts found" cleanly without crashing

If the skill would fail silently or confusingly on a clean project (no .gsd/ directory), add defensive language to Step 1. Document as deviation.

Done when: graceful-failure path is explicit in the skill.

### Task 3: ByteRover Domain Alignment
type: auto

Cross-check: directories created by `install.sh` Step 7 (ByteRover seeding):
```
patterns/ anti-patterns/ expertise/ decisions/ error-rules/ scripts/ domain/
```

Against: curate target domains in `gsd-transition/SKILL.md` Steps 2 and 3.

Verify all curate destinations are in the above list. If SKILL.md references a domain not created by install.sh, either add it to install.sh mkdir or update SKILL.md.

Done when: all curate targets exist in install.sh-created directory structure.

type: auto

Create `.planning/phases/07-integration-installation/VERIFICATION.md` attesting all 5 Phase 7 requirements:

1. INST-01 — `bash install.sh --init-project` completes all 8 steps

For each requirement: state PASS/FAIL and evidence.

Done when: VERIFICATION.md written with all 5 requirements assessed.
