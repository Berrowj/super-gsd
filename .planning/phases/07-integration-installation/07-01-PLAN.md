# Plan 07-01: Validate Install Script and Overlay

## Objective
Verify `install.sh` is correct, portable, and contains no API key requirements. Verify `CLAUDE-OVERLAY.md` teaches the autonomous loop fully. Fix any issues found.

## Tasks

### Task 1: Dry-Run Validation
type: auto

Run `install.sh` with `--dry-run --init-project` and capture output. Verify:
- All 8 steps emit "DRY RUN:" lines
- No step silently fails
- Step counts match actual file counts in agents/, skills/, hooks/ directories
- `--skip-brv` suppresses step 7 output

Done when: dry-run output lists all 8 steps with correct counts.

### Task 2: Cross-Platform Portability Check
type: auto

Scan `install.sh` for non-portable constructs:
- `readlink -f` (macOS: needs `greadlink` or alternative)
- `sed -i ''` vs `sed -i` differences
- `bash`-specific syntax that breaks on `sh`
- Any hardcoded Linux paths (`/usr/bin`, `/usr/local`)
- `command -v` vs `which` usage
- Array syntax compatibility

Also verify shebang is `#!/bin/bash` (not `#!/bin/sh`) — intentional bash dependency is acceptable.

Fix any genuine portability issues found. Document as deviation if fixed.

Done when: no non-portable constructs remain (or all are intentional bash-only with bash shebang).

### Task 3: API Key Audit
type: auto

Search entire `super-gsd/` tree for:
- Strings: `ANTHROPIC_API_KEY`, `API_KEY`, `Bearer `, `api_key`, `token:` (in auth context)
- Any `fetch()` or `http.request()` calls that could hit external APIs without OAuth
- Any `process.env` references that imply key requirements

Verify README and CLAUDE-OVERLAY.md both explicitly state "No API keys required."

Done when: zero API key references found (or all are in comments explaining they are NOT needed).

### Task 4: CLAUDE-OVERLAY Loop Completeness Check
type: auto

Verify CLAUDE-OVERLAY.md teaches all 9 dispatch rules (from the dispatch table), the 4 exit conditions, checkpoint protocol, commit discipline, and token efficiency rules.

Specifically check:
1. Dispatch table has rows 1-9 with correct agent names matching agents/ directory
2. Exit conditions are exactly 4 (not more, not fewer)
3. Checkpoint write uses `Write` tool (not Bash echo)
4. Commit format matches `feat({phase}-{plan}): {one-liner}` pattern
5. ByteRover integration section covers both query and curate operations

Fix any gaps. Document as deviation if fixed.

Done when: all 5 checks pass.

## Verification

```bash
bash super-gsd/install.sh --dry-run --init-project 2>&1 | grep -c "DRY RUN:"
```

Expected: >= 8 lines containing "DRY RUN:"

## Success Criteria
- Dry-run completes without error
- No non-portable constructs in install.sh  
- Zero API key requirements in codebase
- CLAUDE-OVERLAY.md covers all loop mechanics
