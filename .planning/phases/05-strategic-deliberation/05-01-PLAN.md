# Plan 05-01: Termination Conditions and Haiku Gate

## Objective

Add a 3-round hard cap to the CEO agent and brief template, and wire a Haiku-based phase-impact gate into the gsd-deliberate skill so trivial decisions cannot trigger a full board spawn.

## Context

- @super-gsd/skills/gsd-deliberate/SKILL.md
- @super-gsd/agents/gsd-ceo.md
- @super-gsd/templates/brief-template.md

## Tasks

### Task 1: Add termination metadata to brief template

**Type:** auto

Add a `## Termination` section to `super-gsd/templates/brief-template.md` that captures:
- `phases_affected`: integer count
- `max_rounds`: default 3
- `gate_score`: to be filled by Haiku gate

This section is used by both the gate (to read `phases_affected`) and the CEO (to enforce `max_rounds`).

**Done:** brief-template.md contains `## Termination` section with the three fields.

---

### Task 2: Add 3-round hard cap to CEO agent

**Type:** auto

Edit `super-gsd/agents/gsd-ceo.md`:

1. Add `<termination_rules>` block after `<synthesis_rules>`:
   - Hard cap: never run more than 3 rounds total (Round 1 + Round 2 + Round 3 max)
   - Round 3 is only triggered if Round 2 ends in a direct contradiction between Architect and Pragmatist with no movement from either
   - After Round 3: synthesize regardless of disagreement; document the impasse in `## Unresolved Tensions`
   - If brief has `max_rounds` field set lower than 3, respect that lower limit

2. Add to the `<workflow>` block a step 7.5 between Round 2 and synthesis:
   - Check: has `max_rounds` been reached? If yes, proceed to synthesis immediately.
   - Check: has consensus improved since Round 1? If no movement in any position, proceed to synthesis.

**Done:** gsd-ceo.md has `<termination_rules>` block and workflow step 7.5 both present and correct.

---

### Task 3: Add Haiku gate to gsd-deliberate skill

**Type:** auto

Edit `super-gsd/skills/gsd-deliberate/SKILL.md`:

Insert a new `<step_0_gate>` block BEFORE `<step_1_brief>`:

```
## Step 0: Phase Impact Gate

Before creating the brief or spawning the board:

1. Ask the user: "How many project phases does this decision affect? (enter number)"
2. If user provides a brief path: attempt to read `phases_affected` from brief's Termination section.
3. Score:
   - phases_affected < 3 → SKIP. Respond: "This decision affects fewer than 3 phases. Use /gsd-plan or decide directly. Deliberation reserved for cross-cutting decisions."
   - phases_affected >= 3 → PROCEED to Step 1.

Gate model: Haiku (cheap — this is a simple numeric check, not a semantic evaluation).
Gate cost: ~50 tokens.
Gate is MANDATORY. Cannot be bypassed by passing a brief path directly.
```

**Done:** SKILL.md has `<step_0_gate>` as first executable step, gate logic matches spec, skip message is present.

---

## Verification

1. brief-template.md has `## Termination` section with `phases_affected`, `max_rounds`, `gate_score`.
2. gsd-ceo.md has `<termination_rules>` with 3-round cap and impasse handling.
3. gsd-ceo.md workflow has step 7.5 checking round cap before synthesis.
4. SKILL.md has `<step_0_gate>` before `<step_1_brief>`.
5. Gate logic: < 3 phases → skip message, >= 3 phases → proceed.

## Success Criteria

- A user running `/gsd-deliberate new` for a 1-phase decision gets the skip message without board spawn.
- A user running `/gsd-deliberate new` for a 4-phase decision proceeds to brief creation.
- A deliberation that cannot reach consensus after 3 rounds still produces a Decision Memo.
