### Task 2: Verify CEO prompt assembly

**Type:** auto

Create `.planning/phases/05-strategic-deliberation/ceo-prompt-trace.md`:

This file documents the expected CEO prompt assembly for the test brief:

1. **Board member prompt structure** — show the template from `<board_spawn_template>` populated with the test brief content (abbreviated, not full)
2. **Sections that must be present** in each board member prompt:
   - `BRIEF:` — full brief text
   - `PROJECT CONTEXT:` — from STATE.md frontmatter
   - `RELEVANT EXPERTISE:` — placeholder for brv-query results
   - `YOUR ROLE:` — role-specific instructions
   - `RESPOND WITH YOUR STRUCTURED POSITION ONLY. No intro. No summary. Max 400 words.`
3. **Gate check trace** — show what the gate evaluates: `phases_affected = 4`, result `PROCEED`
4. **Round evaluation logic** — list all 4 round-2 trigger conditions from SKILL.md step 4

The trace file is a verification artifact, not runnable code. It proves the prompt assembly logic is complete and correct by mapping each required field to its source.

**Done:** ceo-prompt-trace.md exists and covers all 4 sections above.

**Type:** auto
