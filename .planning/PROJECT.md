# Super GSD Framework

## Vision

A token-efficient, multi-agent autonomous orchestrator built on GSD 1.0.
Combines the best of GSD 1.0 (68 skills, 24 agents), GSD 2.0's orchestrator
patterns (auto loop, checkpoint survival, dispatch rules), and new capabilities
(CEO/Board deliberation, ByteRover memory, model routing, ATC quality gates,
Overwatcher signal maps).

## Goals

1. Token efficiency as the load-bearing architectural constraint
2. Right model for right task (Opus orchestrates, Sonnet executes, Haiku classifies)
3. Query-based memory via ByteRover (replace full file loads)
4. Autonomous loop with checkpoint survival across context windows
5. Strategic decision-making via multi-agent adversarial debate
6. Script registry for utility reuse across phases
7. Live project visualization via Overwatcher signal maps
